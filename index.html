核心价值

不是把文字读出来，而是让内容更容易被消化。

转换的是载体，释放的是时间与注意力。

01

提高碎片时间利用率

把原本无法阅读的移动、等待和家务时间，转化为可持续的输入时间。

02

降低复杂内容的进入门槛

亲和、口语化的知识讲解音色，让冗长或枯燥的材料更容易听下去。

03

保护未公开内容

完成首次安装后可在本地离线生成，文稿与音频无需自动上传到云端。

为什么它是 Agent

它交付的不是一次朗读，而是一个完整结果。

Agent 负责理解用户意图、判断环境是否可用、调用不同工具完成流程，并把可检查的成果返回给用户。

UNDERSTAND

理解任务

识别输入文稿、输出位置与用户真正需要的成品。

CHECK

检查环境

确认模型、运行依赖与本地设备满足生成条件。

ORCHESTRATE

编排工具

协调文本清理、Qwen3-TTS、MLX 与 FFmpeg 完成处理。

DELIVER

交付并说明

返回音频、清理后文稿、运行记录，以及需要人工确认的事项。

从长文到播客

复杂处理留给 Agent，用户只需准备内容并试听成品。

上传或粘贴中文文稿

支持纯文本、.txt 和 .md；标题、列表和链接格式可以保留。

02 · 自动转换

自动清理 Markdown，按标点自然分段，使用 Sohee 音色生成并合并。

本地离线

内容留在自己的电脑里。

当前版本面向 Apple Silicon Mac，首次下载模型后即可离线运行，不需要持续网页服务。

  • 不自动上传用户文稿
  • 不自动上传生成音频
  • 不自动发布到播客或社交平台
  • 保留可检查的本地运行记录
