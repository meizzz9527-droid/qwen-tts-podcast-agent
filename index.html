03 · 如何使用

上传文稿，一句话启动。

准备文稿

提供可直接朗读的中文纯文本、.txt 或 .md 文件。

发送指令

在 Codex 中上传或粘贴文稿，并调用知识播客 Skill。

自动生成

Agent 检查环境、清理分段并在本地完成语音生成。

试听验收

优先试听 1.05 倍速成品，人工抽听确认后再发布。

使用 $qwen-tts-knowledge-podcast
把这篇文稿生成知识播客音频。

输出目录可选。标题、列表和链接等 Markdown 格式可以保留。首次使用需联网下载约 1.65GB 模型，安装后可以完全离线运行。

适合谁

在 Apple Silicon Mac 上创作中文内容的人。

适合内容创作者、知识博主、课程讲师和播客制作者。

  • M1、M2、M3、M4 或后续 Apple 芯片 Mac
  • 至少 4GB 可用磁盘空间
  • 首次安装时可以联网
  • 已准备好可朗读的中文文稿
当前边界

明确限制，稳定交付。

  • 固定使用 Sohee 女声音色
  • 不负责选题、调研和从零写稿
  • 不支持多人对话、背景音乐和复杂混音
  • 英文缩写、人名和生僻词可能需要人工调整
  • 成品需要人工抽听确认
  • 不会自动上传或发布音频
  • 暂不支持 Intel Mac、Windows 和 Linux
